# 用語集

hbg のソースと資料で使う言葉の定義です。

## ストレージまわり

| 用語 | 意味 |
| --- | --- |
| ストレージ | ファイルを置ける場所。`storage.Storage` を満たすもの |
| バックエンド | ストレージの実装。`backend/` の下に1種類ずつある |
| 種別（type） | ストレージの種類を表す文字列。`local`、`dropbox` など |
| 名前（name） | 設定ファイルで付ける呼び名。コマンドで `名前:パス` と書く |
| 解決器（Resolver） | 名前からストレージを組み立てるもの。使われるまで組み立てない |
| 登録（Register） | バックエンドが自分を種別の一覧に加えること。`init()` で行う |

## パスとメタデータ

| 用語 | 意味 |
| --- | --- |
| 起点（root） | 設定で指定する、そのストレージの中での出発点 |
| `SizeUnknown` | サイズが事前に分からないことを表す値（-1）。0（空）と区別する |
| `Features` | そのストレージにできることの申告 |
| オプショナルインターフェース | できたりできなかったりする能力。`Hasher` や `Mover` など |
| 番兵エラー | `storage.ErrNotFound` など、`errors.Is` で判定するための値 |

## 転送

| 用語 | 意味 |
| --- | --- |
| 走査（scan） | 転送元をたどって、何を転送するか決めること |
| 判断（Decide） | 1ファイルについて、転送するかしないかを決めること |
| 許容幅（modify window） | この時間以内の更新時刻の差は同じとみなす、という幅 |
| パス（pass） | 転送の1回ぶん。失敗が残ったらもう1回まわす |
| 余分なもの（extraneous） | コピー元にないのにコピー先にあるもの。`--delete` の対象 |
| 書きかけ（`.hbgpart`） | 書き込み中のファイルに付ける印。一覧には出さない |

## 失敗の分類

`storage.Class` の値です。詳しくは [error-handling.md](error-handling.md) を
見てください。

| 値 | 意味 | 再試行 |
| --- | --- | --- |
| `ClassPermanent` | 待っても直らない（存在しない・権限がない） | しない |
| `ClassRetryable` | 一時的（瞬断・5xx） | する |
| `ClassRateLimit` | 要求が多すぎる | 待ってからする |
| `ClassAuth` | 認証・認可の失敗 | しない。処理全体を止める |
| `ClassCanceled` | 取り消された | しない |
| `ClassUnknown` | 分類できない | する（保守的に） |

## ハッシュ

| 用語 | 意味 |
| --- | --- |
| `DropboxContent` | Dropbox 独自の content hash。4MiB ごとのブロックの SHA-256 を連ねて、もう一度 SHA-256 したもの |
| `QuickXor` | OneDrive 独自のハッシュ。**hbg では計算していません**（[backends.md](backends.md) 参照） |
| 共通のハッシュ | 両側が扱える種類。なければ `--checksum` は使えない |

## 置き場所

| 用語 | 意味 |
| --- | --- |
| `$HBG_HOME` | hbg のファイル一式を置く場所。既定は `$HOME/hbg` |
| 旧レイアウト | 2026年以前の置き場所（`$HOME/hbg_config.yaml` など）。読めるが書かない |
